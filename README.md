# Amazon Webpage

A front-end clone of the Amazon homepage layout, built with HTML and CSS. Made for practice. It is not affiliated with Amazon.

## Sections
- Navigation bar with search box and account links
- Secondary menu bar
- Hero banner
- Grid of eight category boxes
- Multi-column footer

## Files
- `index.html`: page structure
- `style.css`: styling
- Image files: logo, hero banner, and category images (add these to the repository)

## How to run
Open `index.html` in your browser, or view the GitHub Pages link.

## What I learned
Building a multi-section page layout with flexbox and styling it with CSS.
